# PiggyVault

**PiggyVault** — це мобільний додаток для управління особистими фінансами, розроблений на базі Flutter. Додаток допомагає користувачам відстежувати витрати, планувати заощадження, управляти бюджетом та досягати фінансових цілей у зручний та інтуїтивний спосіб.

---

## Основний функціонал

*   **Гейміфіковані заощадження:** Система рівнів, XP та стриків для мотивації.
*   **Дерево навичок:** Розвиток персонажа за класами (Хакер, Магнат, Резильєнтність).
*   **ІІ-коуч:** Персоналізовані поради від ІІ (OpenRouter/DeepSeek) з різними характерами.
*   **Кіберпанк інтерфейс:** Унікальний візуальний стиль з неоновими елементами та терміналом.
*   **Віддалене управління:** Можливість контролювати свій ПК через додаток (для спеціальних квестів).

---

## Архітектура проєкту

PiggyVault побудований з використанням сучасних паттернів розробки на Flutter:

### Керування станом (State Management)
*   **Riverpod:** Використовується для ін'єкції залежностей та реактивного керування станом.
*   **StateNotifier:** Основний інструмент для бізнес-логіки (наприклад, `SavingsNotifier`).

### Зберігання даних (Data Layer)
*   **Drift (SQLite):** Надійна реляційна база даних для транзакцій, цілей та профілів.
*   **Hive:** Швидке Key-Value сховище для налаштувань та локальних кешів.

## Технологічний стек

| Компонент | Технологія | Опис |
|---|---|---|
| **Фреймворк** | Flutter 3.6.x | Кросплатформний UI-фреймворк від Google |
| **Управління станом** | Riverpod | Сучасне керування станом та DI |
| **Локальна БД** | Drift (SQLite) | ORM для роботи з реляційними даними |
| **KV Сховище** | Hive | Швидке сховище налаштувань |
| **Навігація** | GoRouter | Декларативна навігація |
| **ІІ** | OpenRouter (DeepSeek) | Інтеграція з мовними моделями |

## Встановлення та налаштування

### Клонування репозиторію

```bash
git clone https://github.com/fgr966779-rgb/save_quest.git
cd piggyvault
```

### Встановлення залежностей

```bash
flutter pub get
```

### Генерація коду

Проєкт використовує `build_runner` для генерації Drift таблиць та Riverpod провайдерів:

```bash
dart run build_runner build --delete-conflicting-outputs
```

### Запуск

```bash
flutter run
```
