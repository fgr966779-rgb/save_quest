# Глубокий анализ проекта PiggyVault (Май 2026)

## 1. Обзор архитектуры и Технический долг
Проект находится в активной фазе разработки, но накопил значительный технический долг, мешающий масштабированию.

### 1.1 Состояние кода (Lint Analysis)
*   **Всего проблем:** ~375 сообщений.
    *   **Errors (14):** Критические ошибки в `AppTheme` (несоответствие типов Material 3), ошибки типов в `LeaderboardProvider` и отсутствующие стили в `LeaderboardTile`.
    *   **Warnings (27):** Неиспользуемые импорты и переменные, а также проблемы с зависимостями (пакет `uuid` используется без объявления в `pubspec.yaml`).
    *   **Info (334):** Массовое использование устаревшего `.withOpacity()` вместо `.withValues()`.
*   **Стабильность:** Тестовое покрытие практически отсутствует (1 smoke test).

### 1.2 Архитектурные узкие места
*   **Monolithic Notifiers:** `SavingsNotifier.createDeposit` — это "Божественный метод", который делает слишком много: расчеты XP, стрик-менеджмент, валидация достижений, обновление аватара и запись в БД.
*   **Hardcoded Goals:** Логика жестко завязана на две цели (`goal_a` и `goal_b`). Это прослеживается в схеме БД (таблица `Deposits`), логике транзакций и UI. Динамическое добавление целей сейчас невозможно без рефакторинга БД.
*   **Фрагментация данных:** Настройки и часть игровых данных хранятся в Hive, в то время как основные данные — в Drift. Это создает риск рассинхронизации.

## 2. Геймификация и Социальные функции

### 2.1 Дублирование логики (Achievements vs Badges)
*   **Achievements:** Хранятся в таблице `unlocked_achievements`. Логика проверки разбросана по `SavingsNotifier`.
*   **Badges:** Хранятся как JSON-строка в профиле пользователя. Проверка идет через отдельную функцию `checkNewBadges`.
*   **Проблема:** Обе системы проверяют одни и те же условия (стрики, суммы накоплений), но делают это разными способами.

### 2.2 Статус реализации функций
| Функция | Статус | Комментарий |
| :--- | :--- | :--- |
| **Bounties** | Работает | Генерация и проверка контрактов через провайдер. |
| **AI Insights** | Работает | Интеграция с OpenRouter (DeepSeek) через `BankingInsightsCard`. Требует API ключ. |
| **Squads** | Заглушка | Есть таблицы в БД и UI, но нет сетевой части. |
| **Joint Goals** | Заглушка | Локальная реализация без возможности реального приглашения друзей. |
| **Pets** | Базовая | Локальное хранение и базовое взаимодействие (кормление). |
